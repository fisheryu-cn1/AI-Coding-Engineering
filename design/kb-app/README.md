# GraphIt-KB 设计方案集

以本项目已收集的资料库（`references/` + `research/` + `design/`）为初始语料，设计一个具有自动组织、自动收集与内容扩展能力的本地知识库应用，并作为 Agent 知识管理与上下文管理的实验载体。

## 设计依据

方案吸收 `design/` 已有六份文档的共识（混合检索、Schema 先验抽取、结构感知分块、哈希指纹增量、少即是多），并对其中分歧做出裁决：图库选 LadybugDB（嵌入式，Kùzu 社区继任 fork）而非 Neo4j（单机本地化优先；Kùzu 上游已停止维护，选用其社区继任 fork）、不引入 AST 路线、抽取范围克制在核心域 15–25%。各决策的溯源见 03 文档 §11。
