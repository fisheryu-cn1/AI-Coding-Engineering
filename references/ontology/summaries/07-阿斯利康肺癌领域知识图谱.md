# 论文摘要：AstraZeneca BIKG 用于非小细胞肺癌患者生存预测与生物标志物发现

> **原论文标题**：Integrating knowledge graphs into machine learning models for survival prediction and biomarker discovery in patients with non–small-cell lung cancer

## 1. 适用场景

- 在 **生物医药 KG + 临床 ML** 场景下，把领域知识图谱（BIKG、PrimeKG、Hetionet）作为 ML 模型的"先验知识通道"，补全基因 panel 缺失。
- 评估 **不完整基因 panel** 下的生存预测能否通过 KG 投影补偿。
- 评估 **不同 KG embedding 算法**（SocioDim、GLEE、NetMF、RandNE、NodeSketch、BoostNE）在临床生存预测中的适用性。
- 把 ML 框架 + KG API 化，提供给药企研发的可复用 pipeline。

> 锚点：摘要（Abstract）；Introduction；Results §"Framework" / §"OS prediction: NSCLC"；Extended Data Fig. 1。

## 2. 主要观点与方案

### 2.1 问题定位

- NSCLC 患者生存预测复杂：多组学 + 临床特征 + 高度自由度。
- 既往研究未把"先验知识"以可泛化、可复现的方式融入生存模型。

### 2.2 方法（KG + ML）

- 用患者基因签名（mutation status）作为查询投影到 KG，扩展出基因-基因相互作用子图。
- SocioDim 把子图投影到低维 embedding（本文采用 16 维），再聚合到患者级向量。
- ML 用 Random Survival Forest（被评估为最稳定、最可泛化的方法）。

### 2.3 评估数据集

- POPLAR（NCT01903993）+ OAK（NCT02008227）免疫肿瘤（IO）治疗临床试验。
- MSK-MET 2021 NSCLC 原发组织样本数据集。
- 比较 4 种输入：完整基因 panel / 完整 panel + BIKG / 100 基因随机子集 / 子集 + BIKG。

### 2.4 关键发现

- 在完整 panel 上加 BIKG 不显著（C-index 0.600 vs 0.597, p=0.815）。
- 在不完整 panel 上加 BIKG 能恢复丢失的信息（0.527 → 0.598, p=0.873 vs full panel 0.600）。
- OAK 训练模型在 POPLAR 上泛化：BIKG 模型 KM 分层达到统计显著，而 OAK 基因 panel 或 bTMB（cutoff=16）单用未达显著。
- 10 基因模型定义的突变特征在两试验上均得到显著 OS 分化。
