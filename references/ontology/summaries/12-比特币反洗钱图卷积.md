# 论文摘要：Anti-Money Laundering in Bitcoin（用 GCN 做比特币金融取证）

> **原论文标题**：Anti-Money Laundering in Bitcoin: Experimenting with Graph Convolutional Networks for Financial Forensics
> **完整 PDF 文件名**：`aml-bitcoin-gcn_2019.pdf`
> 作者 / 年份：Mark Weber, Giacomo Domeniconi, Jie Chen, Daniel Karl I. Weidele, Claudio Bellei, Tom Robinson, Charles E. Leiserson（MIT-IBM Watson AI Lab / IBM Research / Elliptic / MIT CSAIL），2019，KDD '19 Workshop on Anomaly Detection in Finance，arXiv:1908.02591
> 摘要类型：Agent 设计参考 + 内容索引
> 生成日期：2026-08-12

## 1. 适用场景

- 在 **加密货币反洗钱（AML）** 场景下，使用图神经网络（GCN）处理大规模交易图。
- 设计 **金融欺诈检测 Agent**——交易图（节点=transaction，边=支付流）上做节点二分类（合法/非法）。
- 评估 **LR / RF / MLP / GCN** 在大尺度标注交易数据上的表现。
- 在 **公开账本 + 伪匿名** 的特殊场景下，理解"开放数据赋能调查 vs 伪匿名庇护犯罪"的悖论。

> 锚点：Abstract；§1 Toward Financial Inclusion；§2 Elliptic Data Set；§3 Task and Methods。

## 2. 主要观点与方案

### 2.1 数据集贡献（Elliptic Data Set）

- 时间序列图：203,769 节点（交易）+ 234,355 有向边（支付流）。
- 166 个节点特征：前 94 个为本地信息（时间步、输入/输出数、fee、output volume、相邻交易统计），后 72 个为一跳邻域聚合特征（max/min/std/correlation）。
- 标签：2%（4,545）illicit（class1），21%（42,019）licit（class2），其余未标注。
- 时间：49 个时间步（每步约 2 周），单步内 ~3 小时内上链交易构成一个连通分量。

### 2.2 任务（AML 二分类）

- 预测 illicit transaction（illicit vs licit）。
- AML 行业基线：false positive 90%+，需在不增加 false negative 的前提下降低 false positive。

### 2.3 方法（基准 + GCN）

- 基准：Logistic Regression / MLP / Random Forest（仅用前 94 维本地特征）。
- GCN：2-layer GCN `H(2) = softmax(Â · ReLU(ÂXW(0)) · W(1))`；作者加 "skip" 变体，把中间 embedding 与输入特征拼接。

### 2.4 关键发现

- Random Forest 表现最佳（关系特征缺失下，树模型更鲁棒）。
- 邀请后续工作：融合 RF 与图方法（GCN 缺关系先验、RF 缺图结构）。
- 提供可视化原型，便于在交易图上导航并观察模型性能随时间的演化。

> 锚点：§3 Task and Methods；§3.1 Benchmark Methods；GCN 公式；Results。
