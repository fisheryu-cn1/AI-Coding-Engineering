## 1. 适用场景

- 在 **企业财报（SEC 10-K）** 场景下，构建 S&P 100 全部公司的开放金融 KG。
- 设计 **反思驱动（reflection-driven）抽取框架**——支持 single-pass / multi-pass / reflection-agent 三种模式。
- 使用 **表格感知分块（table-aware chunking）+ schema-guided iterative extraction** 提升结构化抽取质量。
- 多维评估：rule-based CheckRules + 统计验证 + LLM-as-a-Judge。

> 锚点：Abstract；§1 Introduction；§3 Problem Formulation and Schema Design；§4 Methodology；§5 Evaluation。

## 2. 主要观点与方案

### 2.1 问题

- 金融 KG 缺乏大规模开源数据集；现有工作多基于新闻（覆盖窄）或缺乏严格评估。
- SEC 10-K 文档异构（叙事文本 + 表格 + 图片）、监管敏感、价值高。

### 2.2 数据与三元组

- 五元组：(Head Entity, Head Type, Relationship, Tail Entity, Tail Type)。
- 数据源：所有 S&P 100 公司 2024 年 10-K filing。
- 数据集地址：anonymous.4open.science/r/KG-Financial-Datasets-SP-100-529B。

### 2.3 实体 / 关系类型（schema 子集）

- Entity：ORG / PERSON / COMP / PRODUCT / SEGMENT / FIN_METRIC / RISK_FACTOR / EVENT / REGULATORY_REQUIREMENT / ESG_TOPIC。
- Relationship：Has_Stake_In / Operates_In / Produces / Impacts / Involved_In / Impacted_By / Discloses / Complies_With / Supplies / Partners_With。
- Schema 配置：LLM 提议 + 金融 SME 审批（closed IE）。

### 2.4 四层管线

- ① Intelligent Document Parsing（基于 docling，text-only / multimodal；表格保留为 markdown；叙事章节加 section header 标签）。
- ② Table-Aware Semantic Chunking。
- ③ Iterative Prompt & Agent-Driven Triples Extraction（single-pass / multi-pass / reflection-agent）。
- ④ Robust Evaluation Layer（rule + statistical + LLM-as-a-Judge）。

### 2.5 三种抽取模式

- single-pass：效率优先。
- multi-pass：精度优先。
- reflection-agent：反思驱动反馈循环，**64.8% CheckRules 合规 + LLM-as-a-Judge 最佳**。

### 2.6 关联方法对比

- EDC（Zhang & Soh 2024）：Extract-Define-Canonicalize 框架。
- Carta（Carta 2023）：zero-shot GPT-3.5 渐进抽取。
- RAS（Jiang）：Retrieval-And-Structuring，查询规划 + 抽取交替。
- ChatIE：多轮 QA 抽取。
- CESI、WordNet 对齐：传统 schema canonicalization。

### 2.7 应用

- KG-powered entity search / multi-hop QA / signal generation via news integration / graph powered predictive models / network analytics。
