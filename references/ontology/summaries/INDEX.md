## 与 GraphIt-KB 的相关性

- 论文 18（GraphRAG）、19（HippoRAG）、22（LightRAG）、20（KAG）是 GraphIt-KB 的"图路检索"在 P1 阶段的核心参照——尤其 GraphRAG 的"局部→全局"与 LightRAG 的"双层检索"直接可借鉴。
- 论文 24（OG-RAG）的"本体接地"思路与 GraphIt-KB 的"Schema 先验抽取"（FR-2.1）一致——但本项目抽取出 15–25% 核心域实体，更克制。
- 论文 13 / 25 / 21 / 26 的 RDF/SPARQL 评测支撑 GraphIt-KB 选型时的"为什么不选 RDF 三元组库 + SPARQL"（LadybugDB 内置 Cypher + FTS + 向量即可，但本项目把向量交给 LanceDB 避免绑死）。
- 论文 01（LLM-KG 构建综述）提供"自动化本体工程"的成本/质量取舍参考，GraphIt-KB 的 P1 实体抽取策略受其启发。
