# 论文摘要：机器与人类对混淆代码的理解对比（UT Dallas）

## 1. 适用场景

- 当你需要**"人可读性与 AI 可读性是否等价"的实证证据**（如论证人/机可读性分离点命题、评审面向 AI 的代码规范）时，读这篇——它按混淆类型分层给出对齐与不对齐的具体位置。
- 当你要为**人机协作工具选型**建立"模型难度模式与开发者对齐"这一维度（可检查性/可监督性）时，读其 §XI-A 的三条选型含义。
- 当你评估**混淆在 LLM 时代的保护价值**或"良性命名误导 LLM 分析器"的恶意代码风险时，读其 §XI-B。

> 锚点：Abstract; §I Introduction; §III Research Questions; §V RQ1; §VI RQ2; §VII RQ3; §VIII RQ4; §XI Implications

## 2. 主要观点与方案

- **设计**：直接复用 Nguyen et al. 的人类混淆理解研究（50 名本科生、20 个 HumanEval-X 输出预测任务）作为基线，评估 7–9 个 LLM（Llama/Qwen/DeepSeek/Phi/SmolLM 家族，分 reasoning/instruct/coder 三类）在五个混淆层级（L0 原始、L1 重命名、L1b 对抗重命名=语义误导命名、L2 控制流扁平化、L3 组合）上的表现，用 Schulte 的 Block Model（atom/block/relational/macro 四层）定位失败位置（§II; §IV）。
- **RQ1 结果层对齐**：reasoning-tuned 模型与人类任务级难度显著对齐（Spearman ρ=0.30–0.47，均 p<0.05），coder/instruct 模型近零相关（ρ=0.02–0.10）；对齐与准确率是两个维度——最强的 DS-R1-Qwen-7B 并非最对齐，Phi-4 Mini（ρ=0.47）最镜像人类（§V-C; Table IV）。
- **机制定位**：L2/L3 的下降源于 dispatcher 结构从无到有，把推理从局部单元逼到全局执行流重建；dispatcher 复杂度与准确率负相关（Python while-if 状态数 r=−0.196，q=3.08×10⁻²³），且该效应与 CoT 长度无关（r≈0.03–0.05）——是真实理解困难而非推理变长（§V-A）。
- **人类专家反转未被复现**：人类专家在 L1b（对抗重命名）下准确率不降反升（依赖结构而非词汇线索），无任何模型复现该模式；人类语言效应（Python≫JavaScript）也比模型强且模式不同（§V-A; §VI; Table III）。
- **RQ3 CoT 长度=难度信号**：CoT 长度与准确率负相关（ρ=−0.52）；正确回答的 CoT 随混淆层级单调上升（p=0.004）、错误回答不升——长度标记难度而非困惑；人类努力模式是 L0→L1 跳升后平坦（System 1/2 切换），模型是单调扩展（§VII）。
- **RQ4 原子级失败**：对抗重命名仅在**语义置换与标识符级干扰共现**时触发高置信错误（交集子集准确率崩至 21.25%、HCI 率 10.00%，均为全条件最差）；置信度漂移方向任务/模型依赖（§VIII; Table X–XI）。
