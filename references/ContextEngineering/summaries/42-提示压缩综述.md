# 论文摘要：Prompt Compression for LLMs（综述）

> **原论文标题**：Prompt Compression for Large Language Models: A Survey
> **完整 PDF 文件名**：`42-Prompt-Compression-Survey.pdf`
> 作者 / 年份：Cambridge，2024-10
> 摘要类型：Agent 设计参考 + 内容索引（综述类）

## 适用场景

- 做相关综述/比较时参考：需要全面了解 prompt compression 领域的方法分类、技术演进与未来方向。
- 研究者入门 LLM prompt compression 领域的地图（hard prompt vs soft prompt）。
- 工程师选型时需要在 13+ 种方法（LLMLingua、LongLLMLingua、LLMLingua-2、Selective-Context、GIST、ICAE、AutoCompressor、xRAG、UniICL、COCOM、LLoCO、QGC、TACO-RL、PCR、CPC、TCRA-LLM 等）之间比较时参考。
- 调研 prompt compression 与下游任务（QA/RAG/ICL/Agent/Role-play）适配性时查阅。

## 主要观点与方案

综述论文 (arXiv:2410.12388v2, Zongqian Li, Yinhong Liu, Yixuan Su, Nigel Collier, University of Cambridge, Oct 2024) 给出 prompt compression 领域的系统化分类与综述：

1. **两类方法分类**：
   - **Hard Prompt Methods（§3）**：保持可读 token 的方法
     - Selective-Context、LLMLingua（信息熵/困惑度过滤）
     - Nano-Capsulator（改写/释义）
     - LongLLMLingua（长上下文 question-aware）
     - AdaComp（自适应压缩）
     - LLMLingua-2（token 分类）
     - PCRL、TACO-RL、CPC、TCRA-LLM（RL-based）
   - **Soft Prompt Methods（§4）**：学习连续向量
     - CC（Contextual Compression）
     - GIST（gist tokens）
     - AutoCompressor（多段 soft prompt）
     - ICAE（In-context AutoEncoder）
     - 500xCompressor
     - xRAG、UniICL、COCOM、LLoCO、QGC（结合检索/ICL 的方法）

2. **Insights（§4.2）**：attention 优化视角、与 PEFT 的类比、模态整合、新型合成语言。

3. **Downstream Adaptions（§5）**：QA、RAG、ICL、role playing、agent-based、跨学科应用。

4. **Challenges（§6）**：fine-tuning 问题、效率提升有限、与 attention modification 的关系。

5. **Future Directions（§6.2）**：Encoder Optimization、hard + soft 组合、多模态 insights。
