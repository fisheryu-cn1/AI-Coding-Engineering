# 论文摘要：LLM 提示压缩的实证研究

> **原论文标题**：An Empirical Study on Prompt Compression for Large Language Models
> **完整 PDF 文件名**：`44-Prompt-Compression-Empirical-Study.pdf`
> 作者 / 年份：HKUST，ICLR 2025
> 摘要类型：Agent 设计参考 + 内容索引（实证类）

## 适用场景

- 做相关综述/比较时参考：需要了解 6 种主流 prompt compression 方法在同一基准下的系统性 empirical 比较。
- 工程师在 13 个数据集（新闻、科学文章、常识 QA、数学 QA、长上下文 QA、VQA）上选型。
- 关注 prompt compression 对 hallucination 影响的实践者（论文新定义 MaHR/MiHR metric）。
- 关注 prompt compression 与输出长度、模型差异（GPT-3.5 / GPT-4o-mini / Claude-3-Haiku）交互影响的研究者。

## 主要观点与方案

经验研究论文 (arXiv:2505.00019v1, Zheng Zhang/Jinyi Li/Yihuai Lan/Xiang Wang/Hao Wang, HKUST-Guangzhou, Apr 2025; Building Trust Workshop at ICLR 2025) 系统比较 6 种方法：

1. **研究方法**：
   - 6 种压缩方法：KiS、SCRL、Selective Context、LLMLingua、LongLLMLingua、LLMLingua-2
   - 3 个 (M)LLMs：GPT-3.5-turbo、GPT-4o-mini、Claude-3-Haiku
   - 13 个数据集：news, scientific articles, commonsense QA, math QA, long-context QA, VQA
   - 压缩比 ρ = 1 - L_c/L_o（Eq.(1)）

2. **三大方法分类（Figure 2）**：
   - (a) RL-based（KiS, SCRL）
   - (b) LLM scoring-based（Selective Context, LLMLingua, LongLLMLingua）
   - (c) LLM annotation-based（LLMLingua-2）

3. **关键发现**：
   - (Long)LLMLingua 与 LLMLingua-2 在高压缩比下整体优于其他方法
   - 短上下文时所有方法表现都下降；长上下文 + 适度压缩反而能提升性能
   - Prompt compression 影响 response 长度，方向因 LLM 而异
   - 所有方法都增加 hallucination；信息丢失是主因
   - 多模态任务上表现差异大；SCRL、Selective Context、LLMLingua-2 不稳定
   - "the" 等停用词单独影响小，但在长上下文中累积影响显著

4. **新指标 MaHR / MiHR**（Macro / Micro Hallucination Rate）：定量评估压缩引入的幻觉。
