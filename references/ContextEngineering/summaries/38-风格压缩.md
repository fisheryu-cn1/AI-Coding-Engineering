# 论文摘要：Style-Compress 考虑任务特定风格的提示压缩

> **原论文标题**：Style-Compress: LLM-Based Prompt Compression Considering Task-Specific Styles
> **完整 PDF 文件名**：`38-Style-Compress.pdf`
> 摘要类型：Agent 设计参考 + 内容索引

## 适用场景

- 当压缩器在不同任务上需要不同压缩风格（抽取式 vs 生成式、可读 vs 不可读、是否感知任务/位置）时统一框架化。
- 摘要、问答、对话、推理等异构下游任务的 prompt 压缩需求。
- 4 类典型任务上的压缩：BBC News、CNN/DailyMail（摘要）、HotpotQA（多跳 QA）、GSM8K（数学推理）。
- 通过训练得到的 LLM compressor 替代硬编码的过滤算法，适应不同上下文需求。

## 主要观点与方案

论文 (arXiv:2410.14042v1, Xiao Pu/Tianxing He/Xiaojun Wan) 把 prompt 压缩分解为 5 个可调维度（§3）：

1. **location-aware**：压缩时是否考虑被压缩片段在原 prompt 中的位置（影响 lost-in-the-middle 风险）。
2. **abstractive vs extractive**：压缩产物是抽取的原文片段还是重写的自然语言短句。
3. **readable vs unreadable**：压缩结果是否需要保留可读性（影响人审/调试与 LLM 兼容性）。
4. **format-aware**：是否保留原始格式（标点、列表、JSON 等）。
5. **task-aware**：是否在压缩时考虑下游任务或问题。

框架（§3.1-3.4）：
- §3.1 Overview：LLM 作为 compressor，输入 (style 选择, 原 prompt) 输出压缩 prompt。
- §3.2 Adaptation：基于训练数据让 compressor 学习指定 style 偏好。
- §3.3 Instruction methods：通过自然语言指令控制 compressor 选择 style 组合。
- §3.4 Inference：把 (style 选择, 压缩 prompt) 送入目标 LLM。

实现：LLaMA-2-7B 作 compressor，LLaMA-2-13B 与 GPT-3.5 作 evaluator；测试 4 个任务。

## 达到的效果

| 度量 | 结果 | 锚点 |
|---|---|---|
| 压缩比 0.25-0.5 范围 | 在 BBC News、CNN/DailyMail、HotpotQA、GSM8K 上表现匹配或超过原 prompt | §4 |
| 主要优势 | 与单一风格（如纯抽取或纯生成）压缩器相比，Style-Compress 可通过调整风格组合适应不同任务 | §4 |
