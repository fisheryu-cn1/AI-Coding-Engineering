## 1. 适用场景

- 设计 **跨会话 / 长期 Agent** 时需要把"记忆"概念工程化，本文给出统一操作定义与四元组拆解（存储位置—持久性—写入路径—访问方式）。
- 做 **LLM 记忆相关综述 / 比较研究** 时参考：本文提出 parametric / contextual / external / procedural 四分法，避免常见混淆（如 RAG 文档是外部记忆还是上下文记忆）。
- 选择 **遗忘 / 更新方案**（ROME / MEND / MEMIT / SERAC / unlearning / DAPT）时需要权衡目标抑制—邻域保留—下游稳态三轴，本工作给出 Pareto 分析与协议。
- 设计 **评测协议** 时需要去耦"模型能力 vs 信息可得性"，本文提出三设置并行协议（PO / Offline Retrieval / Online Retrieval）+ Minimum Reproducibility Disclosure。
- 给 Agent 系统做 **治理闭环**（admission → rollout → monitoring → rollback → audit）时，本文的 DMM-Gov 框架是参考。

> 锚点：Abstract；§1 Introduction；§3.1 Definition；§3.2 Types；§5 Update & Forgetting；§6 Challenges。

## 2. 主要观点与方案

### 2.1 统一操作定义（§3.1）

- **LLM 记忆** = 在预训练、微调或推理阶段被 **写入** 的、之后可被 **稳定寻址** 并 **系统性影响输出** 的持久状态。
- **记忆四元组**：存储位置 × 持久性 × 写入路径 × 访问方式——避免把记忆和单一载体（权重 / 文档 / KV cache）等同。

### 2.2 四类记忆与边界（§3.2）

- **Parametric memory（参数化记忆）**：固化在权重（特别是 FFN 层）的模式；PO 设置下能召回事实；对时效/长尾敏感；编辑/回滚难度高。
- **Contextual memory（上下文记忆 / 工作记忆）**：推理时由输入和历史形成的激活与 KV cache；few-shot 风格对齐；受位置与长度强烈影响（Lost in the Middle）。
- **External memory（非参数化记忆）**：通过检索注入文档 / 最近邻等；可更新、可审计；典型如 RAG；缺点是索引 / 分块 / 融合都可能注入噪声。
- **Procedural / episodic memory（过程 / 情节记忆）**：跨会话存储结构化事件 / 时间线 / 摘要，Generative Agents / MemGPT 是代表。

边界判断规则（§3.2 Operational criteria）：

- PO 设置下不靠外部仍能稳定召回 → 参数化。
- 必须在 prompt/KV 中存在且对位置敏感 → 上下文。
- 依赖外部索引检索结果并可给出版本级引用 → 外部。
- 跨轮/跨会话需 replay 结构化事件/时间线才一致 → 过程。

特别澄清 **RAG 的"双重身份"**：检索到的文档必须序列化进 prompt 才能进入生成循环——既是外部记忆也是上下文记忆。评测时应 **优先级 = 来源优先**（先评估检索质量 × 引用忠实度），并 **分层指标**：

- Layer 1 检索质量（Recall@k, nDCG）。
- Layer 2 引用 / 忠实度（FActScore, Citation Precision/Recall）。
- Layer 3 上下文利用效率（条件化在正确证据已注入后，测位置/长度敏感性）。

### 2.3 写—读—抑制/更新（R—W—I，§3.3）

- **Write（写）**：预训练把高频高互信息模式压缩进 FFN；LAMA 等探针观察到事实召回；低熵高度重复片段易 verbatim 记忆。
- **Read（读）**：推理中注意力 + KV cache 把 prompt / history 映射成可用规则；induction heads / ICL 的近似梯度下降解释。
- **Inhibit / Update（抑制/更新）**：模型编辑（ROME 秩1 / MEND 低秩梯度 / MEMIT 万级批量）、DPO/SFT、unlearning。
- 三者构成贯穿 **训练—推理—后训练** 的因果链。

### 2.4 评测框架（§4）

- **三设置并行协议**：
  - **Parametric-Only (PO)**：禁用外部证据/工具，考察参数化召回与编辑/遗忘副作用。
  - **Offline Retrieval/Replay**：固定索引或会话记忆，做 stepwise 诊断。
  - **Online Retrieval**：动态知识源，关注时效命中 / 过期 / 拒答校准。
- **报告要求（MRD）**：受控基线（同数据切片+同时间窗 PO/Offline 对照）+ 版本锁 + 统一输出（答案文本 / 引用 / 置信度 / 拒答标记）+ 配对统计（bootstrap/permutation + Holm/FDR）+ 重现细节。
- **四类记忆的评测指标族**（Table 4.1）：Accuracy / Groundedness / Retrieval / Sensitivity & Robustness / Timeliness / Maintainability & Side Effects / Privacy & Memorization / Efficiency & Cost。
- **四类对比维度**（Table 4.2）：能力 vs 信息可得性 / 准确 vs 忠实 / 质量 vs 成本 / 稳定性 vs 不确定性。

### 2.5 更新与遗忘治理（§5）

- **DMM-Gov 动态治理**：DAPT/TAPT + PEFT + 模型编辑（ROME/MEND/MEMIT/SERAC）+ RAG 形成可审计闭环：准入阈值 → 渐进式发布 → 在线监控 → 可逆回滚 → 变更审计证书。
- **三轴 Pareto 分析**：目标抑制 × 邻域保留 × 下游稳态——编辑/遗忘的标准化验证协议。
- **E-MARS+**（情节记忆评测）：跨会话一致性与时间线 replay。
- **侧效应审计**：membership inference / training-data extraction / 安全回归测试。
- **五条工程原则**（§5.4）：外部记忆优先、小步编辑、长任务读写策略、时间戳对齐、隐私与评测去偏。

### 2.6 关键可检验命题（§6）

- 最小可识别性条件 / 最小充分评估卡 / 因果约束的编辑与可验证遗忘 / 何时"检索 + 小窗口 replay"优于超长上下文直读。
