## 2. 主要观点与方案

### 2.1 综述框架（四层）

本文把"context engineering"组织为四层结构：

1. **Components（组件层）**——构成上下文工程的基本单元。
2. **Implementations（实现层）**——这些组件如何被组合成具体技术。
3. **Evaluation（评估层）**——如何测量上下文策略的有效性。
4. **Future（未来层）**——未解之谜与方向。

### 2.2 Components（组件层）

- **Prompt 构造**：指令、上下文、示例三段式；Few-shot / CoT 模板。
- **知识来源**：参数化记忆（模型权重）+ 外部知识（RAG）+ 工具结果 + 长期记忆。
- **上下文结构**：顺序、窗口、压缩、摘要、层级。
- **控制信号**：system / user / tool / function messages 等不同通道。

### 2.3 Implementations（实现层）

按"上下文从哪来 / 怎么组织"分：

- **长上下文**（long context）：Lost in the Middle、anchor prompting、position reweighting。
- **RAG**（retrieval-augmented generation）：BM25 / embedding / hybrid retrieval、reranking、generation fusion。
- **Memory / State**：short-term（KV cache）+ long-term（external store / KG / DB）。
- **Tools / Function calling**：把外部能力作为上下文的延展。
- **压缩 / 摘要**：LLMLingua / LongLLMLingua / RECOMP / generative summarization。
- **多模态上下文**：图像 / 音频 / 视频作为额外信息源。

### 2.4 Evaluation（评估层）

按上下文策略的关键性质分类：

- **有效性**：任务准确率、Pass@k、answer quality。
- **鲁棒性**：位置鲁棒性（Lost in the Middle 现象）、长度鲁棒性、噪声鲁棒性。
- **效率**：token 消耗、延迟、检索成本、缓存命中率。
- **可解释性 / 归因**：引用召回、faithfulness、span-level attribution。
- **安全性 / 隐私**：prompt injection 抗性、verbatim memorization、private information leak。

评测方法：

- **基准数据集**：NaturalQuestions、HotpotQA、SWE-bench、HumanEval、LongBench、Needle-in-a-Haystack、RepoQA 等。
- **指标族**：EM / F1 / Recall@k / nDCG / Faithfulness / Citation Recall / Token 消耗 / Latency。
- **评测协议**：controlled baseline（同数据切片下对比）、paired statistics、multiple-comparison correction（Holm / FDR）。

### 2.5 Future Directions（前瞻）

- **个性化 / 用户级记忆**：跨会话用户画像与情境感知。
- **可证安全的上下文**：在 prompt injection、对抗输入下保持鲁棒性。
- **可解释上下文**：让模型能说出"我为什么用了这段上下文"。
- **多模态融合**：视觉 + 文本 + 代码的统一上下文。
- **Agentic 上下文**：上下文不再只是 prompt 字符串，而是 harness / 工具 / 计划 / 记忆的动态整合（与 Harness-Native SE 论文 11 呼应）。
- **评测新范式**：从单次准确率走向"在动态上下文约束下的长期一致性 / 可恢复性"。

### 2.6 与其他论文的关系

- 与 Harness-Native SE（论文 11）：上下文工程只是控制平面的一个子集；本文综述范围更窄。
- 与 Lost in the Middle（主题中论文 02）：长上下文鲁棒性问题的奠基性实证。
- 与 Memory in LLMs（论文 19）：本文覆盖"上下文"概念，但 LLM 记忆更关注参数化与持久化。
- 与 CodeRAG-Bench（论文 16）：RAG 评测的标准协议对照。
