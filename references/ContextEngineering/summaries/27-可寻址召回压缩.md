# 论文摘要：ARC（可寻址召回压缩——把"指针式证据"留在 prompt 里）

> **原论文标题**：Addressable Recall Compaction for Long Context-Window Control in AI Agents

> 作者 / 年份 / 出版：Thang Dang, Yuma Ichikawa, Sakina Fatima, Koichi Shirahata（Fujitsu Research of America; Fujitsu Limited Japan; RIKEN AIP），2026，arXiv:2607.25066v1

## 1. 适用场景

- 为**长视野 LLM Agent**设计上下文管理框架：解决 trajectory 单调增长突破 context window 的硬失败。
- 当现有 compaction 方法（朴素截断、分层摘要、状态折叠、RAG 检索）都是**不可逆 / 概率不可控**地丢信息时，需要"可定位、可恢复"。
- 当你需要**对每个 historical observation 做单向 vs 双向对照实验**（needle-in-a-haystack）来定量衡量"找回率"时。
- 当关心的是 HBM 带宽 / 推理硬件成本时，可对照报告 T_prefill+T_decode 与 HBM traffic。
- 作为**理论 + 实现**双参考：当 agent framework 已经有 _recall / _recall_meta 工具时，研究 address-conditioning 回收下界。

## 2. 主要观点与方案

### 2.1 核心主张（"先解耦，再给出 address-conditioned recoverability"）

- 现有 compaction 范式 4 种（Truncation、Hierarchical Summarization、State Folding、RAG）都混淆了"该保留什么"和"现在展示什么"，且都 lossy。
- 一条 observation 是否 "recoverable"（vs "lost"）是 compaction 策略的核心安全指标，并以此组织相关工作。
- ARC 把这俩决定**解耦**：永远全量 verbatim 入 ObsStore（content-addressed：SHA1(signature(A) || US byte || O)）；让活跃 transcript 用长度有界逻辑决定展示什么，但每个被替掉的 long observation 留下一个**确定性 dereferenceable pointer §id**，并配 head/tail preview + metadata + _recall §id 提示。

### 2.2 关键机制（§Proposed Method; Figure 2）

- **ObsStore** append-only：每个 observation 拥有 stable id（前 8 hex 字符，碰撞时按 4 hex 增量延展）；记录 payload + 命令签名 + head/tail previews + length + return code + creation step + recall bookkeeping。
- **Bounded-Size Active View**：5 段固定 token budget（task prefix / deterministic summary / recent suffix / 一页 citation catalog / recalled body），K ≤ L；超过 M 时把已 cited 而又变老的 stub 再 collapse 到裸 §id。
- **Recall 动作** `_recall §id`：每轮限 r（默认 2），超过总 budget 时 LRU 召回 body 被回退到 stub；`_recall_meta §id` 轻量恢复 citation-level 元信息。
- **Compaction routine 完全 deterministic、零 LLM 调用**（区别于 LLM_summary）：truncate older thoughts + keep short O inline + cite longer O + keep recent turns verbatim；不重新摘要或改名以保 persistent addressability。
- **Proactive / Reactive 双触发模式**：reactive 模式在 context-overflow 错误之后触发；同一 deterministic routine 在两个模式下保持行为一致。
- **System-level guarantee（Theorem 1）**：i. injective fixed-width id；ii. 任何 compaction 发生前都已 verbatim 入库；iii. 外部 catalog 完整 / prompt 内一页 bounded；iv. K ≤ L 强制。⇒ 有效 observation 始终能由 id 严格恢复（条件在 valid address 而非 agent 决策）。
- **理论下界（附录证明）**：能"在 turn-independent 上下界内 + 精确恢复任意历史"的系统其外部存储必至少线性增长，ARC 的 append-only 增长与该下界一阶匹配。

## 5. 一句话索引（给 Agent 用）

> 做长视野 Agent 上下文压缩时，**别让 compaction 与"是否还能找回"耦合**：把每个 observation 都 verbatim 写入 append-only + content-addressed 的 ObsStore（SHA1 id），活跃视图按长度有界逻辑留 citation handle，让 agent 用 `_recall §id` 原状拉回——在 Needle-in-a-Haystack 上 ARC 拿到 99.40% exact-answer accuracy（vs LLM_summary 88.12%）、LongBench-v2 Hard 上 29.97% vs 28.25%，同时显著降低 HBM traffic 与 prefill+decode 时延。
