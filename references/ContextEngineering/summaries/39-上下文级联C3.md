# 论文摘要：C3 通过两个 LLM 级联的上下文级联压缩

> **原论文标题**：C3: Context Cascade Compression via Cascaded Two-LLM
> **完整 PDF 文件名**：`39-Context-Cascade-C3.pdf`
> 摘要类型：Agent 设计参考 + 内容索引

## 适用场景

- 超长 OCR 文档（百万页级）的端到端文本压缩与重建。
- 需要在低算力（Qwen2.5 1.5B + 3B）下实现接近 GPT-4 级压缩质量的部署场景。
- 知识库索引、检索增强、文档存储等需要 20x-40x 文本压缩比的场景。
- 黑盒 LLM 输入前的预处理：把上百页原始文本压成短摘要再喂给目标 LLM。

## 主要观点与方案

论文 "Context Cascade Compression: Exploring the Upper Limits of Text Compression" (arXiv:2511.15244v2, Fanfan Liu/Haibo Qiu) 提出 C3 框架：用两个小型 LLM 级联完成"压缩-重建"两阶段任务，逼近大模型的压缩上限。

1. **架构（§3.1）**：Encoder = Qwen2.5 1.5B，Decoder = Qwen2.5 3B；两级都是 decoder-only LLM，级联实现 上下文压缩-重建。
2. **Context Compression Encoder（§3.2）**：在 encoder 中插入 learnable context query Q ∈ R^(N×D)，用 causal attention 让 Q 序列通过 cross-attention 读取完整原文；decoder 重建时仅依赖 Q 而不再访问原文，实现 N 倍压缩。
3. **Decoder LLM（§3.3）**：训练目标为文本重建，给 decoder 输入"repeat the text:" + Q 的输出，让其恢复原文。

训练细节：1M 页 OCR 训练数据，40k steps，8x H800 GPU。

## 达到的效果

| 度量 | 结果 | 锚点 |
|---|---|---|
| 20x 压缩比 | 98.4% 重建 precision | §4 |
| 39.4x 压缩比 | 93.3% 重建 precision | §4 |
| 训练规模 | 1M pages OCR, 40k steps, 8x H800 | §3.3 |
