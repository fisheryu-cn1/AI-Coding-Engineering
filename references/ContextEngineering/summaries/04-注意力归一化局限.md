## 1. 适用场景

- **理解长上下文失效的机制根源**：为什么"窗口大 = 用不好"——不是 GPU/算力问题，而是 softmax 归一化本身的容量上限。
- **设计 / 选型 attention 变体**（Sparsemax / SS-Max / SA-Softmax）时：作为"为什么必须替换 softmax"的理论依据。
- **做 top-k / sparse attention 工程**时：提供"critical-N ≈ 0.06L"的经验上限。
- **设计 LLM 训练的温度 / scaling 策略**时：避免 T < 0.1 的训练不稳定。
- **做 Agent 上下文选择 / rerank**时：本文给出"single head 上限 ~80% top-N tokens 可分离"的硬约束，提示 multi-head 协同或显式 selector 必要。

> 锚点：Abstract；§1 Introduction；§4 Discussion。

## 2. 主要观点与方案

### 2.1 核心视角：Attention = Capacity-Limited Selector

- 把 attention 重新理解为"容量受限的检索/选择器"——它在小规模 active set 时工作良好，**超过临界 N 后表现可预测地退化**。
- 推导三个非渐近（non-asymptotic）界，覆盖"距离"、"几何可分性"、"梯度敏感度"三个维度。

### 2.2 三个理论结果

- **Lemma 1 / Corollary 1（权重 O(1/L) 上界）**：对任意 **不显式依赖 L** 的归一化函数 F，其权重 αi 必满足 C1/L ≤ αi ≤ C2/L；softmax 情形还给出 exp 形式界。结论：**所有"长度无关"归一化必然遭遇 vanishing attention**。
- **Theorem 1（距离上界 d̃）**：
  - 固定 top-N 集：d̃ ≤ (1 − ᾱ_N) d1 + max∥xj∥ · [ᾱ_N(L−N) − (1−ᾱ_N)]；
  - 均匀随机 top-N：E[d̃] = (L−N)/L · Σ αi (1 + N/(L−1)∥xi − x̄∥) + ε。
  - Corollary 2：N → L 时 E → 0（距离崩溃），N ≪ L 时 E ∝ Σ ∥αi xi∥。
- **Theorem 2（几何可分性，单 head 上限 ≈ 80%）**：在球面均匀 + 最小间距 δ 的标准假设下，**单个 head 至多区分 ≈ 80% 的 top-N tokens**，超过则衰变；H 个独立 head 可覆盖至 1 − (1 − 0.8)^H ⇒ H=3 时即可覆盖 99%。
- **Lemma 2 / Corollary 3（Jacobian 界）**：对一般归一化 F，∥∇_ℓ α∥_2 ≤ min{∥F'∥_2 / (L min F), ∥F'∥_2² / (L² min F²), 2}；softmax 特化后得经典 **1/(4T)** 不稳定性。

### 2.3 经验验证（§3 / GPT-2 124M）

- 数据：Tolstoy《战争与和平》连续章节，tokenize 用 BPE。
- 距离分析（Fig. 2）：
  - 固定 N=5，L 从 32→1024：距离随 L 线性增长（符合 Corollary 2(i)）；
  - 固定 L=1024，N 从 1→100：N≈20 后距离饱和，理论上下界收紧；
  - **Critical Top-N 通过 KS 检验（α=0.01）确定 ≈ 0.06L**——即"超过约 6% 的 tokens 之后，实测和期望距离统计上不可区分"。
- 几何可分性（Fig. 3）：Ns/N 在 N≈16 后饱和在 0.7–0.85，**理论上限 ≈ 80%**。
- 梯度敏感度（Fig. 4）：T<0.1 时 ∥∇_ℓ α∥_2 按 1/T 增长，**与理论界 min{1/(4T), √2} 吻合**；T≥1 时梯度稳定但选择性丢失。

### 2.4 工程建议（§4 Discussion）

- **保持 top-k 小**：critical-N ≈ 0.06L；超过即边际收益为 0。
- **监控 attention entropy 与 Ns/N**：上升/下降即 head 容量饱和信号。
- **避免过尖 softmax**：T < 0.1 会让 Jacobian 爆炸，建议改用 Sparsemax / SS-Max / SA-Softmax。
- **多 head 协同**：p=0.8 时 H=3 头即可覆盖 ~99% top-N。

## 5. 一句话索引（给 Agent 用）

> **任何"长度无关"的归一化（含 softmax）在长上下文下都会遭遇 O(1/L) 注意力塌缩**——单 head 几何可分性硬上限 ≈ 80%，critical Top-N ≈ 0.06L；Agent 设计中应优先选用稀疏 / 长度感知 / 梯度可控的归一化（Sparsemax、SS-Max、SA-Softmax），并把 top-k 控制在 0.06L 之下、用多 head 协同覆盖。
