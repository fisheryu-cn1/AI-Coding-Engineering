# 论文摘要：ACM（Agentic Context Management ——让 Agent 自主做上下文工具）

> **原论文标题**：ACM: Agentic Context Management for Long Horizon Tasks

> 生成日期：2026-08-12

## 1. 适用场景

- 给**长视野 + 多轮** Agent 设计**内禀无损**的上下文管理框架；借鉴"短时/长时记忆分离"的人类认知模型。
- 当现有压缩 / RAG / 状态折叠方案靠外部监控器或固定启发式触发，与 model 自身推理过程"失配"时——把压缩做成 agent 自己的 action。
- 当需要为模型做**post-training**、但又不想做重型 RL 时——使用 teacher–student on-policy + 对偶约束生成演示数据。
- 当需要对 BrowseComp-Plus、DeepSearchQA、SWE-Bench Verified 这类"密集工具调用 + 长任务"基准统一对比不同压缩 / 记忆策略时。
- 作为**对照参考**：与 ACE / Mem1 / ReSum / ACON / SUPO / AgentFold 在 Compact、Trainable、Lossless、Agent-init、Open-source Data 五维上做对照（Table 1）。

> 锚点：Abstract；§1 Introduction；Table 1 与各代表方法对比。

## 2. 主要观点与方案

### 2.1 核心主张（"无损 + Agent-initiated"）

- 既有压缩要么强制按外部 monitor 触发（不可控时机），要么 learned summarizer 不可逆；把上下文管理转成"model 在推理过程中能调用的工具"才能让压缩时机匹配 model 的推理状态。
- 借鉴人认知：in-context 为 working memory + 外部存储为 long-term memory；model 需要时再 query。
- 两个性质：①lossless ②agent-initiated；模型可以**在峰值到达前**主动压缩并按需查询。

### 2.2 框架（§3 Framework；Figure 1）

- 两个工具：
  - `manage_context(a_{2|6})`：把上一个 summary 边界前的所有消息交 summarizer LLM 压缩，原始 messages 不丢而写入 agent 的 external workspace；每个 summary 都有 unique id 与 raw messages 映射。
  - `query_memory(a_9)`：拿 id 给 querier LLM 检索原始 messages，返回只相关片段。
- 对比 ReAct（终撞上限）和 Summary Agent（外部 monitor 超阈值强制压缩、原消息丢弃）：**ACM agent 自主决定时机**。
- 终止条件不变（answer 或 context 满）；动作空间加两项即可，不改主循环。

### 2.3 训练数据生成（§4，Figure 2）对偶约束

- 起点：两个方向的 on-policy rollouts——
  - **H− 学生轨迹**（无 ACM 工具），teacher 标注**该在何处插入** ACM action（"negative"路径：dead-end loop 处该早点压缩）。
  - **H+ 学生轨迹**（带 ACM 工具），teacher 标注**该删去** ACM action 处，还原成 commit-to-answer 或 deep search（"positive"路径）。
- 教师用参考答案 A* 判断动作是否合理；把"哪一步不该有"也作为软监督。
- **Student Resume Rollout**：学生从 teacher 给出的整改点继续滚、直到完成任务，用 teacher 评估作为监督。
- 在 Qwen3.5-9B 上后训练得到 **ACM-Post-Trained**；不依赖重型 RL。

## 5. 一句话索引（给 Agent 用）

> 设计 Agent 上下文管理时，**别让外部 monitor 强制压缩、也别让模型只能摘要破坏信息——给它两个工具让它自己 manage**：`manage_context` 压缩 + 把原文写入外部 workspace；`query_memory` 拿 id 精准召回；teacher–student on-policy + 对偶约束（"哪里该有、哪里不该有"）做后训练；Qwen3.5-9B-ACMPostTrained 在 BrowseComp-Plus +27%、DeepSearchQA +16%、SWE-Bench Verified +8%（vs ReAct），同时峰值 token -20%、多 trial consistency 上升；Table 1 中五维全 ✓ 的同时开源完整 data pipeline。
