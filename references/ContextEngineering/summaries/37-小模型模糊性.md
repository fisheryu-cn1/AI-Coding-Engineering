# 论文摘要：DisambiguSLM 用小模型消解 LLM 提示语义模糊性

> **原论文标题**：DisambiguSLM: Small LM Resolves LLM Prompt Semantic Ambiguity
> **完整 PDF 文件名**：`37-SLM-Ambiguity.pdf`
> 摘要类型：Agent 设计参考 + 内容索引

## 适用场景

- LLM 复杂推理中 prompt 存在指代歧义、隐含假设缺失、时间歧义等语义模糊问题。
- 廉价地提升 LLM 在 GPQA、AGIEval-MATH、LIAR、WSC、BBH-Navigate 等高难度推理任务上的可靠性。
- 需要在闭源 API (GPT-4o-mini/LLaMA-3-70B/DeepSeek-V3) 上以极低额外成本 (~0.02/任务) 增强性能的工程场景。
- 把 SLM 当作 LLM 的"前置解歧器"，让小模型专注于语义澄清而把推理留给大模型。

## 主要观点与方案

论文 (arXiv:2604.23263v1, UESTC + Kyung Hee University, Zhenzhen Huang et al.) 提出三阶段 DisambiguSLM 框架（§3）：

1. **Risk Identification (L1)**：基于语义风险函数 R(Q) = H(A_Q) + γ|B_Q| 识别 prompt 中的歧义/缺省/时间不明等问题，H(A_Q) 为回答问题的信息熵，|B_Q| 为所需额外上下文大小，γ 控制信息增益-上下文成本权衡（Eq.(1)）。
2. **Consistency Verification (L2)**：SLM 生成候选澄清与重写版本，与原始 prompt 做一致性比对，过滤会显著改变原意的候选。
3. **Semantic Integration (L3)**：把澄清后的去歧义 prompt 注入主 LLM 的上下文，LLM 在此基础上作答。

实现细节：Llama-3.2-1B 作为 SLM；目标 LLM 选 GPT-4o-mini / LLaMA-3-70B / DeepSeek-V3；评估 5 个 benchmark：GPQA、AGIEval-MATH、LIAR、WSC、BBH-Navigate。
