# 论文摘要：Telegraph English 通过结构化符号改写做语义提示压缩

> **原论文标题**：Telegraph English: Semantic Prompt Compression via Structured Symbolic Rewriting
> **完整 PDF 文件名**：`41-Telegraph-English.pdf`
> 摘要类型：Agent 设计参考 + 内容索引

## 适用场景

- 5 步以上 LLM agent 系统的 prompt 压缩，在压缩比与下游任务精度之间做精细权衡。
- LongBench-v2 等长文档理解任务中需要 40-50% 压缩比且保持高保真度的场景。
- OpenAI GPT-4.1/4o/4o-mini/4.1-nano/微调 GPT-4o 等 5 个不同目标 LLM 的统一压缩。
- 需要可人工审计的"符号化"压缩产物（不是模糊的 soft prompt）的研究与生产场景。

## 主要观点与方案

论文 (arXiv:2605.04426v1, Mikhail L. Arbuzov et al., Palo Alto Networks, May 2026) 提出 Telegraph English (TE) — 用一套受电报启发的符号字典对自然语言做结构化改写。

1. **Foundations（§3.1）**：三大设计原则 — fidelity 优先于 brevity；原子化行结构（每行一个原子事实）；默认大写降低 token 熵。
2. **Symbol Vocabulary（§3.2）**：~40 个符号（=, →, ⇒, ∴, ∵, ↑/↓, ∧/∨/¬, ≈, VS 等）覆盖逻辑、因果、对照、时空等语义关系。
3. **Tags（§3.3）**：PAST/NOW/FUTURE, LIKELY/POSSIBLE, AGENT/PATIENT, CTX, DEF 等元注释标签，为语义歧义提供机器可读消歧。
4. **Compressor Self-Verification（§3.4）**：12-point quality gate + 6-pass distillation sequence，让 compressor 自检保真度；选用 GPT-4.1 作为 compressor。

实现细节（§4）：LongBench-v2 数据集，339 个文档切分为 4,081 chunks；评估 5 个 OpenAI 模型（GPT-4.1, GPT-4o, GPT-4o-mini, GPT-4.1-nano, fine-tuned GPT-4o）。

## 达到的效果

| 度量 | 结果 | 锚点 |
|---|---|---|
| 平均压缩比 | 0.585（即 41.5% reduction） | §4 |
| 压缩比范围 | 0.13 - 1.57（部分段落因密集语义更短，部分则因需保细节略长） | §4 |
| GPT-4.1 准确率 | 99.1% @ ~50% 压缩 | §4 |
| Pipeline-level 成本 | 5-step agent $16 / 1K calls（vs LLMLingua-2 $33/1K） | §4 |
