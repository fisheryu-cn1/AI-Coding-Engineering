# 论文摘要：PCToolkit 即插即用的统一提示压缩工具包

> **原论文标题**：PCToolkit: A Unified Plug-and-Play Prompt Compression Toolkit
> **完整 PDF 文件名**：`43-PCToolkit.pdf`
> 摘要类型：Agent 设计参考 + 内容索引

## 适用场景

- 做相关综述/比较时参考：需要统一的接口测试 5+ 种 prompt compression 方法在同一基准上的表现。
- 工程师选型：在 Selective Context、LLMLingua、LongLLMLingua、SCRL、KiS 等方法之间快速 A/B 测试。
- 多任务、多数据集（10+）的统一评估：GSM8K、BBC News、Arxiv、ShareGPT、BBH、LongBench、Gigaword、DUC2004、BNC、Broadcast、Google。
- 教学/研究场景下需要 plug-and-play 工具链快速复现 SOTA。

## 主要观点与方案

PCToolkit (arXiv:2403.17411v1, Jinyi Li/Yihuai Lan/Lei Wang/Hao Wang, HKUST-Guangzhou/SMU/SCUT, Mar 2024) 提供统一的可插拔 prompt compression 框架：

1. **架构（Figure 1）**：4 大模块
   - **Compressors**：Selective Context、LLMLingua、LongLLMLingua、SCRL、KiS
   - **Datasets**：10+ 评测数据集
   - **Metrics**：BLEU, ROUGE-1/2/L, BERTScore (P/R/F1), Edit distance, Accuracy
   - **Runner**：统一运行入口

2. **Unified Interface（§4.2）**：`PromptCompressor` 类，`compressgo` 方法接收 prompt 与目标压缩比，调用指定 compressor 内部实现。

3. **Compression Ratio 定义**：ρ = 1 - L_c/L_o（与 LongLLMLingua 等一致）。

4. **评估 Table 3-5**：在 reconstruction、summarization、LongBench、BBH/GSM8K (Boolean Expression, Movie Recommendation, Web of Lies, GSM8K) 上系统性比较 5 种 compressor。

5. **HF Demo**：HuggingFace Spaces 上提供交互式 demo。

注：PCToolkit 主要贡献是统一接口与跨方法对比框架，而非单一方法 SOTA。
