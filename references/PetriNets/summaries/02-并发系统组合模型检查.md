# 论文摘要：Compositional Model Checking of Concurrent Systems, with Petri Nets

> **原论文标题**：Compositional model checking of concurrent systems, with Petri nets
> **完整 PDF 文件名**：`Compositional model checking of concurrent systems.pdf`
> 作者 / 年份：Paweł Sobociński（ECS, University of Southampton, UK）；2016，EPTCS 204:19–30，doi:10.4204/EPTCS.204.3
> 摘要类型：教程式综述 / 形式化方法参考
> 生成日期：2026-08-12

## 1. 适用场景

- 设计 / 评估 **并发和分布式系统的形式化验证工具**时，需要"组合性"思路来抑制状态爆炸。
- 学习 **Petri Nets with Boundaries（PNB）** 这一组合代数：把每个 transition 看成跨边界的分布式同步动作。
- 实现 **reachability / coverability 检查**的算法时，想用"局部 + 语言等价最小化"替代全局状态空间枚举。
- 把过程代数（process algebra）思想与 Petri 网语义对齐，用于解释"为什么 emergent behaviour 在 PNB 里不存在"。

> 锚点：Abstract；§1 Introduction；§2 Compositional modelling: Petri nets with boundaries。

## 2. 主要观点与方案

### 2.1 核心立场：Petri 网可以做成组合性形式化

- 长期以来 Petri 网被描述为"非组合"模型，工具依赖全局状态空间。本文主张 **Petri Nets with Boundaries（PNB）**这一组合代数能改变这一现状。
- 关键观察：① 一个 transition（同步动作）可拆分到两个 component；② transition 的"输入 / 输出"是 component 的局部属性，不是 transition 的全局属性。
- 用 LTS（2-labeled transition system）刻画每个 boundary 的交互；`;`（沿共享边界组合）和 `⊕`（并行堆叠）两个操作均为笛卡尔积的变体。
- 范畴论视角：PNB 与 2LTS 都是 **prop**（strict symmetric monoidal category，对象为自然数）；翻译是 prop homomorphism，因此组合性在形式上严格成立。

> 锚点：§2 Compositional modelling: Petri nets with boundaries；Definition 2–3（Composition with boundaries 与 2LTS rules）。

### 2.2 到达性检查的"消解 + 最小化"算法

- 组件 → NFA：每个 component 的局部 reachable markings 与"期望 marking"构成 NFA 的初始 / 接受状态。
- 利用 **weak language equivalence**（弱等价，对内部 0-标签动作透明）作为 PNB 操作下的同余，可把组件在组合前先最小化。
- 自底向上 evaluate 表达式树：(i) 叶子 → NFA；(ii) 内部节点 = 合成两个 NFA → 最小化；(iii) 每步检查 language emptiness（即可达性）。
- 自动化原型：**Penrose** 工具（Sobociński 等实现），是首个利用组合性做 reachability 检查的工具。

> 锚点：§3 Compositional reachability checking；Algorithm 步骤 (i)–(iii)。

### 2.3 跨连接（boundary）的非局部正确性

- 同步动作的关键：组成双方必须就**共享边界上的标签**达成一致。
- 即使是 1-safe 网，reachability 本身是 **PSPACE-complete**（Cheng–Esparza–Palsberg 1993）；但若网是模块化（重复结构，固定点出现），Penrose 在多个标准 benchmark 上能以数量级超越全局状态空间工具。
- 2LTS 的 transition 标签形如 α/β（α 为左侧 boundary 0/1 串，β 为右侧），弱等价对应 ε-closure 的语义。

> 锚点：§3（counter example 与 dining philosophers 风格示例）；Theorem 4 (Compositionality)；§4 Future work。

### 2.4 局限与未来方向

- 局限：算法依赖"良好分解"；稠密网（如 clique）边界膨胀使 NFA 不可控。
- 未来方向：① 用 prop / 信号流图代数做更广的模型检查；② 把固定点检测机制嵌入 Penrose 以处理参数化网；③ 自动分解（rank-width 启发）；④ 推广到 **infinite state PNB**（covers coverability）。

> 锚点：§4 Future work。

## 5. 一句话索引（给 Agent 用）

> 当面对并发系统的模型检查 / 状态爆炸问题时，把 Petri 网改写为 **PNB（带边界的 Petri 网）代数表达式**，让 Penrose 风格的工具用"局部 NFA + 弱语言等价 + memoisation"把指数长 firing sequence 化为线性时间——这是 Petri 网组合验证的范例。
