# 专用 Agent 装配流程方法 v1（D1-S3）

> 日期：2026-08-17（P1/P2 交界产出；场景一执行后 checklist 化为 v2）
> 话题标签：[D1]（步骤 3/5 含 [D1+D3]，步骤 2/7 含 [D1+D2]）
> 依据：组件目录 v1（选配）、场景画像问卷 v1（入口）、范式选型决策树（护栏）、组件划界与契约指南（契约完整性）、可观测设计清单 v1（预埋）、kb-app 案例（产物环节用模板集 v0）
> 首次执行：场景一 review-pi（pi 首发；DSH 为迁移参照）——执行记录写入 `experiments/`，本文件只在执行后修订。

---

## 流程总览

```
①场景画像 → ②能力清单 → ③组件选配（含迁移参照登记） → ④上下文与提示组装
      → ⑤评估集与门禁（观测预埋） → ⑥装配实现与验证 → ⑦迭代循环
```

原则：**L2 先行、L5 必配、L1 慎用**（组件目录 §3）；契约不完整的组件不得进入 ⑥；观测在 ⑤ 预埋而非事后补。

## ① 场景画像

- 动作：用《场景画像问卷 v1》九问 + 附加问作答，产出画像卡（模板见问卷 §3；实例见 `experiments/01-场景一画像-代码评审agent.md`）。
- 检查点：范式走查有结论；护栏清单已列；风险 ≤3 条且各有对策或验证计划。

## ② 能力清单

- 动作：从画像推导 agent 必备能力（动词短语，如"理解 diff""检索规范""生成分级意见"），标注每项能力的知识来源（内蕴 / 外部知识及其供给方式——契约指南 §1 三段模型）。
- 检查点：每项能力都能映射到 L2/L3 组件或明确"需自研"；外部知识缺供给方式的项标 ❓ 并回到画像补问。

## ③ 组件选配（含迁移参照登记）

- 动作：按组件目录五层选件；每件登记四契约字段 + 档位 + **迁移参照**（DSH 等价形态与预计接入成本——D1-S5 数据积累）。
- 检查点：契约四字段齐（缺失=契约不完整，禁入生产）；F-绑定组件逐条记录依赖的宿主 API 面。

## ④ 上下文与提示组装

- 动作：确定每次 LLM 调用的上下文构成（系统提示 + skill + 仓库上下文源 + 任务输入 + 参照物），设定 token 预算与溯源锚点格式；用模板集 v0 的对应模板撰写产物（意见卡/规范文档等）。
- 检查点：输入契约可断言（预算/必含字段/锚点存在）；skill 内容遵循 06 规范式结构（适用范围/操作规程/红线）。

## ⑤ 评估集与门禁（观测预埋）

- 动作：[D1+D3] 按可观测设计清单 v1 预埋 L1–L5 观测点、选日志契约（建议：本地全量落盘+导出治理）、定质量实体（scores + 在线代理）；构建评估集（标注来源 + 指标口径 pass@1/pass^k + 阈值）；设门禁（schema 校验 + 红线 + 变更触发回归）。
- 检查点：评估集有基线运行记录；门禁在 CI 可触发；观测首份轨迹报告可产出。

## ⑥ 装配实现与验证

- 动作：按 pi 的装配面实现（SDK `createAgentSession` 或 extensions + skills + 工具注册；优先复用 examples/ 70+ 示例模式）；跑 DoD 验证。
- 检查点：DoD 逐项带执行证据与环境口径（模板集 R11）；契约断言同形（R8）。

## ⑦ 迭代循环

- 动作：错误分析（对照标注集与人工复审结论）→ 资产修订（skill/模板/评估集，递增版本）→ 回归门禁 → 重新基线；人工复审结论回流标注集。
- 检查点：每次迭代有变更登记与回写（R9/R12）；迁移参照登记同步更新。

## 与其他方向的接口

- [D1+D2]：②的能力-知识三段登记与④的产物模板直接使用方向二工具；⑤的标注集构建即 D2-S4 规约-验证对的实例化现场。
- [D1+D3]：⑤是方向三可观测清单的首次实施；⑦的回流数据供 D3-S3/S5。
- 实录要求：场景一执行全程按步骤记录（耗时、卡点、修订），产出《装配实录》——流程 v2（checklist 化）的唯一依据。
