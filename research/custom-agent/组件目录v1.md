## 1. 复用性档位（三档）

| 档位 | 含义 | 证据 |
|---|---|---|
| **F-通用**（框架无关） | 纯文本/标准协议，跨 harness 直接迁移 | Agent Skills 标准（SKILL.md）被 pi 与 DSH 同时采用；DSH 生态 claude-bridge/claude-move 专做跨工具迁移 |
| **F-配置**（配置式组装） | 声明式配置可完成的组装级定制 | DSH cordis.patch.yml 三层挂载（bundle→patch→settings）——普通用户改 YAML 即重组 harness |
| **F-绑定**（框架绑定） | 依赖宿主 API/事件系统，迁移需重写 | pi ExtensionAPI 25 类钩子；DSH ctx 能力接缝 |

## 3. 选配规则（与场景画像问卷联动）

1. **L2 先行**：上下文构建组件（skill/模板/上下文源）是 F-通用主力且成本最低，任何场景优先从 L2 配起（两因素模型：先解决输入匹配与外部信息供给）；
2. **L5 必配**：MAST FC3 23.5% + Agentic QA 证据——验证/观测组件是必备件；最低配置 = 遥测（OTel GenAI 语义）+ 一个行为契约执行器（门禁）；
3. **L1 慎用**：行为干预是 F-绑定重资产，仅在 L2/L3 不够时引入；引入时同步登记演化契约（回写义务）；
4. **契约完整才可生产**：组件条目的四契约字段（见模板）缺失即标记"契约不完整"。

## 4. 组件条目登记模板

```
组件名 / 层 / 档位
来源：（自研 | pi 示例 N | DSH 插件 X | 通用标准）
功能：一句话
输入契约：必含上下文/格式/预算/参照物
输出契约：schema/语义/受控词表
行为契约：eval 集位置/红线/口径（pass@1|pass^k）
演化契约：版本策略/回写义务
依赖：宿主 API 面（F-绑定时列明）
登记日期 / 状态（生产可用 | 试验 | 弃用）
```

## 7. v1 边界与 v2 计划

- v1 是**分类规范 + 选配规则**，尚非可检索的实例库——实例登记自场景一装配开始（P2 产出：实测组件库）；
- 待补：其他 harness（Kimi Code / Claude Code）定制机制对比列（materials 待收集项），支撑 D1-S5 迁移成本矩阵；
- 与契约指南的联动字段在场景一中首次实例化并检验易用性。
