## 1. 指标定义

### 1.1 召回三口径（对照评估标注集）

| 口径 | 定义 | 测量方法 | 性质 |
|---|---|---|---|
| **启发式召回**（上界） | 案例期望意见的关键词（ASCII 标识符 ≥2 个，或 1 个 + 溯源文件信号）在意见卡文本出现 | `score_review.py --anchor <锚点>` | 上界——关键词可来自排除性/无关表述，必然高估 |
| **语义严格召回** | 案例缺陷的**机制**被意见显式表达（机制、位置、建议与人工评审同源） | 人工逐案例核定（登记于 `evals/README.md` §0） | 下界——同义改写可能被误判未中 |
| **语义宽松召回** | 严格命中计 1，半命中（根因/部分路径被表达但意见不完整）计 0.5 | 同上 | 区间上界补充 |

**引用规范**：任何召回数字必须标注（口径 × skill 版本 × 锚点 × 清洁/污染 × **模型**）——跨模型 run 不与单模型 run 混算（notes/07 §5）。

### 1.2 可靠性口径（pass@k）

- **pass@1**：单次运行的表现（默认报告三口径召回）。
- **pass^k**（k 次独立清洁运行全部命中的比例）：以**意见配对率**近似——意见身份用**稳定标识（命中规则编号 ∪ 关联对象文件）**，**禁止**用标题词+级别+溯源文件三元签名（v1 伪影：0% Jaccard 假象，实为解析失败/级别漂移 P0↔P1/措辞自由；见 run78 轨迹报告）。
- 当前基线（k=2, v4, f62f287 清洁）：意见配对率双向 100%（run7 的 13 条全部可在 run8 配对，反向同）。

### 1.3 过程指标

| 指标 | 定义 | 当前数据 |
|---|---|---|
| 构建/装配耗时 | 场景从画像到首跑的墙钟时间 | 第 1 场（工件+评估集）单日；第 2 场首跑当日 |
| 组件复用率 | 装配中 F-通用/F-配置档组件占比 | 7 件登记中 F-通用 5 件（71%） |
| 单次运行成本 | token in/out、轮次、工具调用数 | run1: 128.7K/20.8K/65 轮；run2: 118.9K/43.0K/91；run3: 207.4K/77.3K/110；run7/8 见轨迹报告（成本方差最高 1.7×，意见量方差 2×，均列为独立观测量） |
| 问题类型分布 | 意见按 范围缺口/设计错误/实现偏离/测试缺陷 计数 | 首批数据：run6（20/1/3/0，自判待复核）；run7（8/0/3/0）；run8（11/2/3/5）——agent 自判信度未标定，复核前仅作趋势参考 |
| 新发现率 | 未入标注集意见中"真发现"占比（人工复核） | run6 复核：12 真/0 误报（4 条代码级核证） |

## 2. 测量前提（评估有效性三前提 + 防泄漏双禁）

1. **清洁工作区**：运行前归档既有意见卡（`reviews/ → reviews/archive/`）；指令显式禁读 research/evals/reviews/scripts 目录（run6 污染教训：读取先前意见卡会污染召回，该 run 数字不可引用）；
2. **同 skill 版本**：pass^k 只在相同规则集版本内计算（跨版本 v1→v4 的意见集剧变 24–27%，不可混算）；
3. **锚点对应**：每案例用其 review_base 锚点评判（F 系列锚 6e1abeb、N 系列锚 e7c9aa9，勿与 f62f287 混）；
4. 防泄漏双禁：禁读评审锚点之后的提交；禁读评估材料（含标注集与历史意见卡）。
5. **模型标识登记**：意见卡评审者字段与轨迹报告均含模型名；换模型的 run 独立成组（notes/07 §5）。
