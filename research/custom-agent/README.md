# 方向一：基于可定制 Agent 框架（pi / DSH）快速构建专用 Agent 的方法

## 方向说明

以 pi（badlogic/pi-mono）和 DSH（DeepSeek Harness）这两类"极简内核 + 插件/扩展"路线的可定制 agent 框架为实验载体，研究**面向特定应用场景快速形成定制化专用 agent 的方法**：

- 可复用组件的识别、粒度划分与接口规范（extension / plugin / skill / prompt template / 工具集）
- 针对具体场景的"分析 → 设计 → 快速落地"工作流程
- 该工作流程本身的方法论沉淀（场景特征分析框架、组件选配决策依据、验证与迭代机制）
