### [P1] `RELATES_TO` 边 MERGE 模式缺 `kind` 区分键，同 (src, dst) 不同 kind 关系互相覆盖（RR-4 #3 合并键完整 + RR-5 幂等性）

- 溯源 + 证据：
  ```python

  def upsert_edges(self, rel: str, rows: list[dict]) -> None:
      ...

          ...

              f"MATCH (a:{src_label} {{{src_pk}: $src}}) "
              f"MATCH (b:{dst_label} {{{dst_pk}: $dst}}) "

              params,
          )

  RelDef("RELATES_TO", "Entity", "Entity", {
  ```

  - 设计意图（schema.py `kind` 在 RELATES_TO 受控词表 9 个：`extends/contradicts/applies/evaluates/improves-on/part-of/instance-of/uses/compares`）要求 kind 是边的区分维度。
