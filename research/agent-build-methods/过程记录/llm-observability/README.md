## 方向说明

研究 LLM 作为核心组件后的**可观测性**问题，覆盖两个观测对象与同构的三段方法论：

1. **LLM 核心软件系统**（主题 A）：运行情况（延迟/token/工具调用/上下文/异常）与实际任务质量（成功率/幻觉/规范遵循/接管率）两个观测面；研究可观测设计（RQ-A1）、观测数据收集整理（RQ-A2）、数据驱动的迭代决策（RQ-A3）。
2. **AI 辅助开发过程**（主题 B）：观测对象从软件扩展到整个开发过程——评价**人的工作**、**AI 辅助工具的工作**、以及**人-AI 通过文档/提示词交互**的效率与质量；研究过程观测设计（RQ-B1）、量化体系（RQ-B2）、反馈迭代方法（RQ-B3）。

定位：不是"接监控面板"，而是把可观测性作为一类设计关切纳入 LLM 软件系统设计与开发过程管理——与传统可观测性（logs/metrics/traces）和工程效能度量（DORA/SPACE）的关系是核心辨析点。
