### [P1] runner.py::run_holdings — skip_existing 用全局 MAX(report_date) 误判，新季度永远不会被自动发现
- 类型：实现偏离
- 溯源：src/fundseeker/runner.py:407-419
- 证据：
```python
if skip_existing:
    latest_report_date = (
        session.query(func.max(HoldingReport.report_date)).scalar()
    )
    if latest_report_date is not None:
        reported_ids = {
            r[0]
            for r in session.query(HoldingReport.product_id)
            .filter(HoldingReport.report_date == latest_report_date)
            .distinct()
            .all()
        }
        query = query.filter(~ProductInfo.id.in_(reported_ids))
```
过滤条件取数据库全局最新 report_date，凡已持有该日期报告的 product 一律跳过。注释自承认"once a product has the newest known quarter it should not be re-fetched until a newer quarter is discovered"，但代码语义是"已被最新季度覆盖的 product 永远跳过"，不是"被最新季度覆盖的 report 行跳过"。
- 维度：RR-5 幂等与重放（"重跑/重放路径是否幂等"——重复执行错过新季度）
- 建议：改为按 product 维度取 MAX(report_date) 子查询 LEFT JOIN，全局 max > per-product max 才重抓；新季度发布后下一次 cron 自动覆盖。
- 错误成本：业务语义错——一旦 product A 持有 2026-03-31 报告，2026-06-30 发布后 run_holdings 永远不会自动抓取 product A；operator 必须传 `--no-skip-existing` 全量重跑才能发现。确定性强。

### [P1] utils/http.py::PoliteHttpClient._request_with_retries — 4xx 与 5xx/Timeout 无差别重试，725 基金批次最坏膨胀至 ~8 小时
- 类型：实现偏离
- 溯源：src/fundseeker/utils/http.py:171-184
- 证据：
```python
except requests.Timeout as exc:
    last_exception = exc
    if attempt < self.max_retries:
        backoff = 2 ** attempt + random.uniform(0, 1)
        time.sleep(backoff)
    continue
except requests.RequestException as exc:
    last_exception = exc
    if attempt < self.max_retries:
        backoff = 2 ** attempt + random.uniform(0, 1)
        time.sleep(backoff)
    continue
```
`requests.HTTPError`（`raise_for_status()` 抛出）继承自 `RequestException`，所有 4xx（404/403/401/400 等）走第二条 except 与 Timeout/5xx 一同重试。
- 维度：RR-7b 外部系统输入防御（确定性错误应识别并快速失败）/ RR-5 幂等（重放路径与故障路径耦合）
- 建议：区分 `requests.HTTPError`：4xx 除 408/425/429 视为确定性错误立即 raise；Timeout 与 5xx/408/425/429 保留重试。
- 错误成本：Eastmoney 对无股票持仓的债基/货基确定性返 404；max_retries=3 × 5-10s 间隔 × 725 基金 ≈ 最坏 ~8 小时（修复提交描述与此一致）。确定性错误（4xx 不会随时间自愈）被反复重试。
