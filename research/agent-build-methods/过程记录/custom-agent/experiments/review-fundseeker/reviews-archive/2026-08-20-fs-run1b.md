- 类型：实现偏离（设计语义"礼貌采集+弹性"未包含 4xx 重试逻辑；RR-7b 要求按契约校验）

- 证据：http.py:127-143：
  ```
  except requests.RequestException as exc:
      last_exception = exc
      if attempt < self.max_retries:
          backoff = 2 ** attempt + random.uniform(0, 1)
          time.sleep(backoff)
      continue
  ```
  所有 RequestException 一律 4 次（max_retries=3 + 首次），含 400/401/403/404/410 这类永久失败。raise_for_status() 抛 HTTPError（RequestException 子类）落入同分支；客户端也未读 response.headers.get("Retry-After")。

- 建议：把异常分流 —（a）HTTPError 且 4xx（除 408/429）→ 不重试，记录并抛出；（b）HTTPError 429/503 → 读 Retry-After，与 backoff 取大；（c）Timeout/ConnectionError → 维持现有重试+退避
- 分级依据：行为错误（永久失败浪费 4×(30s+backoff) ≈ 152s/URL，对批量采集是确定性放大错误成本）— 评估为 P1（结合全量产品的累计放大效应）
