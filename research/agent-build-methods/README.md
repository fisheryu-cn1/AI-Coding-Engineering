## 5. 续接指南（新项目起步）

1. **先处理未决项**（`过程记录/人工待办事项清单-P3-v1.md`）：**P3-2** 三方向综合报告终审（三条主张表述 + 证据抽查 + 对外形态决策：工程报告定稿/论文改写/模板包）；**P3-3** 定稿判定确认 + 遗留研究项排期裁定（eval-hygiene git 形态规则验证、裁判校准、阶段-模型性价比实验、fundseeker 领域契约类案例、跨框架实迁、V1.1 重打包——清单见规划 §8.5）。
2. **恢复入口阅读顺序**：本 README → 综合报告 §0/§5（10 分钟掌握主张与证据）→ 按需深入（评审场景→总纲+工作包；新 agent 场景→问卷+装配流程+组件目录；评估→口径卡+规约-验证对；过程观测→自观测报告）。
3. **复用约定**：评审类任务直接装 `评审工作包-V1`（先跑裸模型基线再决定规则预算）；任何引用实验数字必须带口径卡口径；任何知识资产交付前配规约-验证对；新项目应写自己的 AGENTS.md 而非复用本项目的（本项目约定含大量本项目特有规则）。
4. **方法遗产**：日志的 [方法]/[教训] 标注与三次阶段评审决策记录，是"对话式研究怎么做"的完整样本——上一轮总体评价指出本项目最耐久的资产是过程技术（口径纪律/污染分类学/人工环节可观测化），复盘时优先从这里取材。
