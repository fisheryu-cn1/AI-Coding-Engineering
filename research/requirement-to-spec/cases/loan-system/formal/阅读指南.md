# 如何人工阅读 UML 模型（本案例操作指南）

## 三种读法

| 方式 | 操作 | 适用 |
|---|---|---|
| **图**（主） | 浏览器打开 `concept-model.svg`；或 VS Code 装 PlantUML 插件后在 .puml 内预览 | 审计整体结构与关系 |
| **文本** | 直接读 `concept-model.puml`（类块+关联行+注释，已语法校验） | 逐属性核对 |
| **大纲** | `model-outline.md`（从 .puml 抽取的注解/枚举/类/关联清单） | 快速定位某条需求对应的元素 |

## 审计动作（对照 translation-audit.md）

1. 图中每个类 → 问"对应哪条登记 ID？"→ 对照表应有行；
2. 每个属性 → 原文是否真有此字段？（防添译）；
3. 缺了什么 → 原文有而图中无的实体/规则 = 漏译（回 S2 或加对照表"弱化"行）；
4. 注释 `@disjoint` / `Z1~Z3` → 决策点逐条确认。

## 渲染命令（改图后重跑）

```bash
cd formal
java -jar ../../../tools/env/jars/plantuml.jar -checkonly concept-model.puml   # 语法门
java -jar ../../../tools/env/jars/plantuml.jar -tsvg concept-model.puml        # 渲染
```

注意：PlantUML 渲染器不支持单行 `enum X {...}`（生成器支持，两者语法面不同——已全部展开为多行）。
