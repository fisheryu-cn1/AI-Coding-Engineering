## 需求总览

- 业务目标：搭建面向个人用户的消费贷款管理系统，支持在线申请贷款、自动审批、电子签约的最小可用闭环。
- 成功标准：完成 Borrower / LoanOrder / CreditResult 三实体的核心维护；实现 M1 申请、M2 自动审批、M3 电子签约；前后端均可依赖安装并编译通过；提供 SQL 脚本与 README。
- 范围内：基础数据维护（增删改查）、业务记录提交、详情查看、简单状态流转、评分规则参数化配置、合同费率展示、SQL 初始化脚本、README。
- 范围外：复杂审批链、规则引擎、自动任务、电子签章组件、文件预览、导出报表、多层级统计。

**澄清结论（补充证据）：**
- Q-001：评分规则为固定可配置阈值——按收入、负债等指标评分，分数≥阈值即通过；具体阈值/权重由配置表维护，默认给一套合理值。
- Q-002：贷款用途为固定枚举，仅含装修、教育、旅游、医疗 4 类。
- Q-003：合同费率为固定费率，由配置表维护（年化利率、服务费、逾期罚息等）。
- Q-004：默认费率经产品确认——年化利率 3.5%、服务费率 1%、逾期罚息率 5%；配置表可调，可参数化配置。
