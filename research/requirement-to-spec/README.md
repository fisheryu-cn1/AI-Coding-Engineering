## 设计原则（从备忘证据直接推导，方法规范不得违背）

1. **确定性边界**：LLM 只出现在翻译、建议、回译三个辅助位；一切"判定"走确定性检查器（备忘 §8.2）。
2. **翻译审计点前移**：人工审计的是翻译件本身（NL↔形式化对照），不是只审检查结果——漏译/弱译在下游不可见（意图对齐之墙，备忘 §8.2/FM03）。
3. **反懒惰修复**：每处修改必须引用 justification（unsat core 类证据）并标注修改类型（澄清意图/修正翻译/补缺——禁止"调整形式化以消除信号"）（备忘 §8.2，Cline cast-to-Any 教训）。
4. **调度非存量**：下游消费的是切片（工作集），不是全量注入（备忘 §8.3，2602.11988 实证）。
5. **人在回路三形态**：人工检验机器产出（审计/裁决）；机器检验人工产出（检查器）；AI 辅助人（建议/预填/回译）。
6. **方法优先于工具**：每环节先定义人工可执行的方法并试点，验证后再自动化。
