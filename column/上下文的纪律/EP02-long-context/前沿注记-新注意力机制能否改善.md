## 1. 原理分析：三类机制对准三个问题

### 1.1 U 形位置偏差（LitM）

- **DSA**：中间信息能否被用，取决于 indexer 是否把它选进 top-k。选择逻辑与位置理论上是解耦的（按相关性打分）——这提供了削弱位置偏差的结构可能；但 indexer 是学出来的，大概率继承同样的训练分布偏差（长程依赖在训练数据中稀少）。更重要的质变：未被选中的 token 从"低权重"变成"零权重"，**软盲区变硬盲区**。
- **KDA**：状态式记忆没有显式位置变量——信息生存取决于"写入时的相关性 × 门控保持力"，而非放在第几个位置。结构上削弱了首因优势（无 attention sink 式的起点聚集），但衰减默认偏向新信息、近因可能强化；1/4 比例的 MLA 全注意力层周期性兜底精确检索。
- **小结**：两条路线都让"位置"从显性变量变成隐性变量，偏差形态预期从"按位置凹陷"转为"按可检索性筛选"——被显式线索指向的信息（问题里出现的关键词）待遇大幅改善，无显式线索的信息利用率依旧低。

### 1.2 有效窗口 ≪ 标称窗口（MECW）

- 新机制主要扩张的是**可负担的窗口**：KV cache 与注意力计算的成本，这正是标称窗口能标到 1M 的前提。但 MECW 类"利用率"受制于三个与成本无关的瓶颈：①DSA 的 indexer 召回率（top-k 必须命中所需 token）；②KDA 的状态容量（每通道可存信息量有限）；③长程任务的训练信号密度。
- 换言之：新机制解决"装得下"，不直接解决"读得好"。MECW 论文里最先崩的恰恰不是检索型而是聚合型任务（summarization / find-and-sort）——这类任务需要同时触碰大量 token，top-k 稀疏与常数状态都在结构上丢弃全局聚合所需的信息。

### 1.3 断崖退化（Wang，RoPE 混叠）

- Wang 的断崖主因是 RoPE 位置混叠：L 超过 ≈2π/θ 后远端位置不可区分。**DSA** 选中 token 后仍做带相对位置编码的标准注意力，若 θ 不随窗口放大，混叠依旧；但"1M 默认窗口"的宣称意味着位置编码必然重标定（更大 θ 或 YaRN 类缩放）——RoPE 悬崖预期**外移**而非消失。**KDA** 用衰减式位置处理而非绝对距离匹配，不存在混叠型断崖；对应失效模式是状态干扰/饱和，形态可能是渐进遗忘。
- 按 Wang 自己的统一式 Lc = min{L_RoPE, L_attention, L_info}：KDA 类模型的约束项从 L_RoPE 换成 L_attention/L_info——瓶颈换了位置，min 的存在没变。

## 3. 总体结论

1. 新注意力机制解决的是长上下文的**经济学**（成本/延迟），三篇论文测的是**利用率**（训练分布问题）——前者是后者的必要条件，不是充分条件。
2. 对专栏三条主张的净效果：U 形曲线形态改变（部分改善）、MECW 差距分任务两极化（检索型改善、聚合型不动）、断崖外移但"有临界点"的本质不变。
3. 工程含义不降反升：标称窗口越标越大（1M），"按自己的任务实测有效窗口"的纪律越重要——**窗口越标越大，尺子越要自备**（候选金句）。
4. 诚实边界：V4 架构细节部分为博客级信息；效果推断无实测依据；若后续有官方论文或第三方复测（如 NoLiMa/HELMET 对 V4/K3 的跑分），成稿时以实测替换本注记的推测表。
